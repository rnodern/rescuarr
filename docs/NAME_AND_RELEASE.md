# Name, ownership, and publication

**Rescuarr** — *No download left behind.*

A GitHub repository under your account reserves only `owner/rescuarr` within that GitHub namespace. It does **not** reserve the name across GitHub, grant a trademark, or register a domain.

## Publication checklist

1. Create a new repository called `rescuarr` under the intended owner's GitHub account.
2. Use **Public** if you want a visible, timestamped open project identity. Avoid adding a GitHub-generated README, licence or gitignore: these are already in this starter.
3. Push the local `main` branch using the commands in `PUBLISH.md`.
4. Decide whether to publish under your personal account or an owned organisation; repo transfers are possible later.
5. Check relevant trade marks (e.g. IP Australia's trade mark search), and do not imply registered protection unless obtained.
6. Check domain registrar availability live for `rescuarr.com` and optional other TLDs, then purchase only if desired.
7. Reserve official social handles later if a public launch warrants it.
8. Select an open-source licence before inviting external code contributions; the starter intentionally has no licence.

No package-name reservations, domain purchases, social account registrations, or trade mark filings have been completed by this starter.
